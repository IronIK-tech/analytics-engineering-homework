# Практична робота 08: SQL-аналітика в Google BigQuery

Набір із 11 SQL-запитів різної складності до публічного датасету інтернет-магазину одягу `thelook_ecommerce` у Google BigQuery. 

## Датасет

Публічний датасет `bigquery-public-data.thelook_ecommerce` (вигаданий інтернет-магазин одягу). У роботі використовуються чотири таблиці:

| Таблиця | Опис |
|---|---|
| `orders` | Замовлення |
| `order_items` | Позиції замовлень (окремі товари в чеку) |
| `products` | Товари |
| `users` | Покупці |

## Інструменти

- Google BigQuery Studio (режим Sandbox, без платіжної картки)
- Git / GitHub

## Як запустити

1. Відкрий [console.cloud.google.com/bigquery](https://console.cloud.google.com/bigquery) і увійди в Google-акаунт (Sandbox вмикається автоматично).
2. Додай публічний проєкт: **+ Add → Star a project by name → `bigquery-public-data`**.
3. Скопіюй запити з файлу `practice_08.sql` у редактор BigQuery і натисни **Run**.

Кожен запит у файлі позначений коментарем `-- Завдання N`. Дані читаються лише з `bigquery-public-data.thelook_ecommerce`. Оскільки датасет публічний і може оновлюватися, конкретні числа в результатах з часом можуть відрізнятися.

## Завдання

| № | Що рахуємо | Ключові конструкції |
|---|---|---|
| 1 | Топ-10 країн за кількістю покупців | `GROUP BY`, `ORDER BY`, `LIMIT` |
| 2 | Виторг і кількість проданих позицій за категоріями | `JOIN`, `SUM`, `ROUND` |
| 3 | Кількість замовлень зі статусами `Complete` і `Shipped` | `WHERE ... IN`, `GROUP BY` |
| 4 | Продажі по місяцях за 2024-2025 роки | `FORMAT_DATE`, `EXTRACT`, `AVG` |
| 5 | Категорії з виторгом понад 100 000 | `HAVING` |
| 6 | Топ-10 товарів за виторгом | `JOIN`, групування за кількома колонками |
| 7 | Відсоток повернень за категоріями | `COUNTIF`, розрахунок частки |
| 8 | Унікальні покупці й середній вік за категоріями | три `JOIN`, CTE (`WITH`), `DISTINCT` |
| 9 | Рейтинг місяців 2025 року за виторгом | віконна функція `RANK()` |
| 10 | Приріст виторгу до попереднього місяця | `LAG()`, кілька CTE |
| 11 | Топ-3 товари в кожній категорії | `ROW_NUMBER()`, `PARTITION BY`, `QUALIFY` |

## Що відпрацьовано

- Об'єднання кількох таблиць (`JOIN`) та групування з агрегатними функціями
- Фільтрація рядків (`WHERE`) і згрупованих результатів (`HAVING`)
- Робота з датами: формат `YYYY-MM`, витяг року
- Умовна агрегація (`COUNTIF`) і розрахунок відсотків
- Підзапити у вигляді CTE (`WITH`)
- Віконні функції: `RANK`, `ROW_NUMBER`, `LAG`, а також `QUALIFY`
